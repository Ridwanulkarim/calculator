# Apple UI Calculator

A sleek, responsive Apple-style calculator built using modern HTML5, CSS3, and JavaScript.

## Features

- **Apple Design Language**: macOS/iOS dark theme aesthetic with translucent window headers, SF Pro typography, and color-coded keypad buttons.
- **Full Calculator Logic**: Supports basic arithmetic operations (`+`, `-`, `×`, `÷`), sign toggle (`±`), percentages (`%`), decimal points, and clear (`C`/`AC`).
- **Dynamic Text Scaling**: Display font resizes automatically to fit large numbers gracefully.
- **Keyboard Navigation Support**:
  - `0-9` : Number inputs
  - `+`, `-`, `*`, `/` : Standard operators
  - `Enter` or `=` : Calculate result
  - `Escape` : Clear display (AC/C)
  - `Backspace` : Delete last digit
  - `%` : Percentage computation

## Getting Started

Simply open `index.html` in any standard web browser or run a local static web server.
